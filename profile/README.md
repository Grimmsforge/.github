# Grimmsforge

**Small, standalone World of Warcraft addons. Each does one thing, properly.**

</div>

---

Grimmsforge is the main source control organisation where our [World of Warcraft addons](https://www.curseforge.com/members/Grimmsforge)'s are built and kept. The brief is the same for all of them: lightweight, focused on a single job the default UI does badly, and self-contained - no required libraries (unless directly embedded), no telemetry, no RGB.

## What Our Add-ons Aim For

- **Standalone** - Where possible, no required libraries unless there's a genuine reason for one.
- **Rules-compliant** - nothing that automates input or skirts Blizzard's restrictions. So, Blizard ToS compliant.
- **Quiet** - Minimise disruption, provide options to reduce visual noise etc.
- **Open source** - released under the Apache License 2.0, there may be some additional Notices here and there.
- **Kept current** - updated each patch as the game changes.

## World of Warcraft Supported Versions

Add-ons will typically always be updated for:

- Retail (Public Release)
- Retail PTR

Then alternative versions of World of Warcraft are developed on a per addon basis for the following versions:

- Forever
- Classic MoP
- Classic TBC
